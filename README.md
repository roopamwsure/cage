# CAGE

**CAGE — Control Assurance Governance Evaluation**

CAGE is a vendor-neutral consequence-assurance layer for consequential actions taken by AI agents and autonomous systems.

## Status

CAGE is under active development.

Current target: **v0.5 — Generic Consequence Core**

The v0.5 objective is to establish domain-neutral semantics for consequence identity, decisions, effects, replay, idempotency, evidence, and Warrant foundations.

## Scope

CAGE does not replace agent runtimes, IAM, authorization systems, policy engines, guardrails, approval systems, observability platforms, or cloud security controls.

CAGE focuses on the business consequence boundary.
