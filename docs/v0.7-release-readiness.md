# v0.7 release readiness review

Review basis: feature branch through `2379886` (2026-09-24), plus the local
`0.7.0` release-candidate metadata and packaging changes. This records
evidence against the required gates in
[`v0.7-developer-product.md`](v0.7-developer-product.md), section 19. It is
release-candidate evidence. It is not evidence of a published release.

## Evidence available

| Gate group | Evidence and status |
| --- | --- |
| C1–C6 correctness | Facade tests cover dispatch reservation, recovery, eligibility, replay, verification, and reconciliation; architecture mapping is in the [public API](v0.7-public-api.md). Code review of the full release candidate remains to be recorded. |
| D2–D3 experience | Quickstart and three disposable scenarios print Decision, adapter observation, verification, Effect, and Warrant information; examples run in the installed wheel CI job. |

Python was 3.13.2 and `[System.Environment]::OSVersion.VersionString` reported `Microsoft Windows NT 10.0.26200.0`. The reported elapsed time was 0.22 minutes. This was an author rehearsal using provided PowerShell commands, not an unfamiliar developer following the published Quickstart independently. |
| D4, S4, O2 integration boundaries | [Integration guide](integration-guide.md) describes public adapter/verifier contracts, target correlation, recovery, local state ownership, and trust limits. |

CLI inspect prints lifecycle metadata rather than payloads or reference contents; commit `8398cbf` escaped control characters in displayed record IDs after a diagnostic review. On Windows Python 3.13.2 the user reported 12 CLI tests and 493 total tests passing at `8398cbf`.
